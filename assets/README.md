# Ember sprite sheet

`ember-sprites.png` was generated with the built-in image generation tool for this project. The original transparent PNG is preserved. Its equal 2 by 2 cells are awake, blinking, happy, and sleeping, in reading order. QML selects a cell at runtime without modifying the image.

## Generation prompt

Use case: stylized-concept. Asset type: production pixel-art sprite sheet for Ember, a cute fantasy dragon hatchling desktop pet. Create one square 1024x1024 PNG with a genuinely transparent alpha background. EXACT layout: 2 by 2 grid of equal 512x512 cells, no gridlines. Each cell contains exactly one full-body view of the SAME character, with identical scale, lighting, proportions and palette. Character: adorable small emerald/teal dragon, round head and plump cream-gold belly, two small ivory horns, expressive amber eyes, tiny batlike wings with warm amber membranes, short clawed feet, curled tail ending in a small warm orange fin. Friendly cozy fantasy creature, polished charming 16-bit game pixel art, crisp deliberate square pixel clusters, dark teal outlines, limited harmonious palette, no smooth painting. Three-quarter view looking slightly left toward the user. Big readable silhouette at small desktop size. Top left cell: awake sitting contentedly, open eyes. Top right cell: same sitting pose blinking, eyes gently closed. Bottom left cell: same dragon delighted, joyful crescent eyes, slightly lifted wings. Bottom right cell: same dragon asleep curled on its own tail, eyes closed, no props. Fit each dragon fully inside its cell with at least 48px clear transparent padding on all sides. Keep the sitting poses feet baseline consistent at y=440 within their cells. Sleeping pose also sits on same baseline. No text, lettering, labels, speech bubbles, frames, ground, scenery, shadows outside the character, extra characters or checkerboard pattern. This is a sprite asset, not an image of a sprite sheet on paper.
